# Aesthetic Directions

Pick one direction and commit to it. Adapt these to the domain instead of pasting them unchanged.

## Operational / SaaS

- **Use for**: dashboards, admin panels, CRM, developer tools, financial tools, internal operations.
- **Type**: clear sans for body, compact mono for IDs, metrics, timestamps, and logs.
- **Palette**: neutral surfaces with one clear action color and one status palette. Avoid saturated full-page color.
- **Layout**: dense grids, clear tables, persistent filters, predictable navigation, high information scent.
- **Motion**: minimal; use it for state changes and attention, not spectacle.
- **Signature move**: strong alignment, crisp dividers, compact badges, inline actions, keyboard-friendly controls.

## Editorial

- **Use for**: essays, portfolios, launches with strong written content, cultural products.
- **Type**: expressive display serif or high-character grotesk paired with readable body type.
- **Palette**: ink, paper, one accent, real imagery where relevant.
- **Layout**: strong type hierarchy, asymmetric columns, pull quotes, image bleeds, disciplined whitespace.
- **Motion**: subtle reveal, scroll-linked affordances only if they improve reading.
- **Signature move**: magazine-like section rhythm or a distinctive typographic masthead.

## Industrial / Technical

- **Use for**: infrastructure, robotics, security, manufacturing, developer products.
- **Type**: sturdy sans, mono numerics, terse labels.
- **Palette**: graphite, white, muted steel/teal, one caution or active accent.
- **Layout**: panel grids, coordinates, rails, measurement marks, visible system state.
- **Motion**: linear transitions, scanning indicators, progress bars, command feedback.
- **Signature move**: labeled panels, hard rules, status strips, precise metrics.

## Playful / Productive

- **Use for**: creative tools, education, lightweight consumer apps, games.
- **Type**: friendly display paired with highly readable body.
- **Palette**: varied but controlled; use contrast and clear state colors.
- **Layout**: direct manipulation, visible controls, generous hit targets, lively empty states.
- **Motion**: responsive feedback, satisfying transitions, no delay on core tasks.
- **Signature move**: tactile controls, custom cursors or sprites where appropriate, strong hover/focus feedback.

## High-Contrast Launch

- **Use for**: landing pages, launches, campaign pages, focused product offers.
- **Type**: bold display with restrained body copy.
- **Palette**: dark/light contrast plus one memorable accent.
- **Layout**: first viewport names the product or offer; hint at the next section on all viewport sizes.
- **Motion**: hero asset or scene should feel alive but not block reading.
- **Signature move**: real product imagery, generated bitmap imagery, or an immersive scene instead of abstract decoration.

## Selection Rules

- Start from audience and workflow, not taste.
- Pick fonts before palette; type character drives the rest.
- Use one signature visual idea. Two is usually clutter.
- If the repo already has a design system, treat these as tuning directions, not replacement themes.
