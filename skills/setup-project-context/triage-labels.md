# Triage Labels

The skills speak in terms of seven canonical triage roles: two category roles and five state roles. This file maps those roles to the actual label strings used in this repo's issue tracker.

| Codex role         | Label in our tracker | Meaning                                              |
| ------------------ | -------------------- | ---------------------------------------------------- |
| `bug`              | `bug`                | Something is broken                                  |
| `enhancement`      | `enhancement`        | New feature or improvement                           |
| `needs-triage`     | `needs-triage`       | Maintainer needs to evaluate this issue              |
| `needs-info`       | `needs-info`         | Waiting on reporter for more information             |
| `ready-for-agent`  | `ready-for-agent`    | Fully specified; an agent can work without new input |
| `ready-for-human`  | `ready-for-human`    | Requires human implementation                        |
| `wontfix`          | `wontfix`            | Will not be actioned                                 |

When a skill mentions a role, use the corresponding label string from this table.

Before applying these labels to a hosted issue tracker, verify that every label in the right-hand column exists in that tracker. If a label is missing, create it or update this file to map the role to an existing label before publishing or triaging issues.

Edit the right-hand column to match whatever vocabulary you actually use.
