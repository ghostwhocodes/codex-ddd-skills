# Structures

## Binary Contrasts

Avoid stock reversals:

- "Not because X. Because Y."
- "X is not the problem. Y is."
- "The answer is not X. It is Y."
- "It feels like X. It is actually Y."
- "Not just X, but Y."

Prefer the direct claim. If the contrast adds real information, keep it in one clear sentence.

## Negative Lists

Avoid listing what something is not before naming what it is:

- "It is not A. It is not B. It is C."
- "This is not a process problem or a tooling problem. It is a trust problem."

Prefer naming C first, then mention A or B only if the distinction matters.

## Dramatic Fragments

Avoid fragments that try to manufacture weight:

- "That's it."
- "That's the tradeoff."
- "One word: ..."
- "And that changes everything."

Prefer complete sentences with the actual consequence.

## False Agency

Avoid giving human action to abstractions:

- "The decision emerged."
- "The data tells us."
- "The culture shifted."
- "The complaint became a fix."

Name the actor when it matters:

- "The team decided."
- "The maintainer read the data and changed the default."
- "The support team fixed the bug after three reports."

## Passive Voice

Passive voice is fine when the actor is unknown or irrelevant. Rewrite it when the actor matters:

- "The setting was changed" -> "The migration changed the setting"
- "Mistakes were made" -> "The release script deleted the tags"
- "The issue was fixed" -> "The patch validates the token before decoding it"

## Meta-Commentary

Remove prose that announces the prose:

- "In this section, we will..."
- "The rest of this document explains..."
- "Let me walk you through..."
- "As we will see..."

Let headings and structure carry orientation.
