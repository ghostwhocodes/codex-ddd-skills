# Phrases

Cut or rewrite these unless they appear in quoted text.

## Throat-Clearing

- "Here's the thing"
- "Here's what"
- "Here's why"
- "The truth is"
- "The reality is"
- "It turns out"
- "Let me be clear"
- "It is worth noting"
- "At the end of the day"
- "When it comes to"
- "In today's landscape"

Rewrite by starting with the claim itself.

## Emphasis Crutches

- "This matters because"
- "Make no mistake"
- "Let that sink in"
- "Full stop"
- "Game-changer"
- "Actually"
- "Really"
- "Truly"
- "Simply"
- "Fundamentally"

Rewrite with the consequence, not the emphasis.

## Business Jargon

| Avoid | Prefer |
| --- | --- |
| navigate challenges | handle problems |
| unpack | explain |
| lean into | accept, use, commit |
| landscape | situation, market, codebase |
| deep dive | analysis, review |
| double down | commit, increase |
| circle back | return, revisit |
| moving forward | next, from now |
| on the same page | aligned, agreed |

## Vague Claims

These are not wrong by themselves, but they usually hide the useful sentence:

- "The implications are significant."
- "The stakes are high."
- "This is critical."
- "The reasons are structural."
- "This is a deeper issue."

Name the exact implication, stake, risk, structure, or issue.
